# Literature survey

Metadata verified against Crossref on 2026-11-22. DOI metadata confirms identity, not a full-paper critical appraisal. Read the original papers before the viva. The last column states relevance/limitations for THIS project; it is not a claim that the cited authors omitted an experiment. No cross-paper accuracy ranking is asserted.

| Ref | Author, year, publication | Method / contribution | Relevance | Scope limitation |
|---|---|---|---|---|
| [1](https://doi.org/10.1109/TBME.2004.827072) | Schalk et al., 2004, IEEE Transactions on Biomedical Engineering. **BCI2000: A General-Purpose Brain-Computer Interface (BCI) System** | BCI acquisition platform | Documents BCI2000; use alongside the official PhysioNet dataset description. | Acquisition infrastructure, not an accuracy benchmark for our pipeline. |
| [2](https://doi.org/10.3389/fnins.2013.00267) | Gramfort, 2013, Frontiers in Neuroscience. **MEG and EEG data analysis with MNE-Python** | MNE signal-analysis software | Supports transparent EEG loading and processing. | Software reference; does not validate this classifier. |
| [3](https://doi.org/10.1016/S1388-2457(99)00141-8) | Pfurtscheller et al., 1999, Clinical Neurophysiology. **Event-related EEG/MEG synchronization and desynchronization: basic principles** | Event-related synchronization/desynchronization | Physiological motivation for mu/beta power features. | Does not guarantee that fixed bands work equally well for all participants. |
| [4](https://doi.org/10.1109/86.895946) | Ramoser et al., 2000, IEEE Transactions on Rehabilitation Engineering. **Optimal spatial filtering of single trial EEG during imagined hand movement** | Common spatial patterns | EEG-specific supervised spatial feature extraction. | Relevant alternative; CSP is not implemented in this one-combination project. |
| [5](https://doi.org/10.1109/MSP.2008.4408441) | Blankertz et al., 2008, IEEE Signal Processing Magazine. **Optimizing Spatial filters for Robust EEG Single-Trial Analysis** | Robust spatial filtering | Discusses EEG spatial filters and robust single-trial analysis. | Spatial filtering differs from our unsupervised spectral-feature SVD. |
| [6](https://doi.org/10.3389/fnins.2012.00039) | Ang et al., 2012, Frontiers in Neuroscience. **Filter Bank Common Spatial Pattern Algorithm on BCI Competition IV Datasets 2a and 2b** | Filter-bank CSP | Combines multiple frequency bands and spatial filtering. | Different datasets/representations; reported scores are not directly transferable. |
| [7](https://doi.org/10.1007/BF00994018) | Cortes et al., 1995, Machine Learning. **Support-vector networks** | Soft-margin support-vector classification | Foundational optimization behind SVM. | General theory, not evidence of EEG performance. |
| [8](https://doi.org/10.1023/A:1009715923555) | Burges, 1998, Data Mining and Knowledge Discovery. **A Tutorial on Support Vector Machines for Pattern Recognition** | SVM tutorial | Explains margins, support vectors and kernel methods. | A tutorial rather than a new EEG experiment. |
| [9](https://doi.org/10.1162/089976698300017467) | Schölkopf et al., 1998, Neural Computation. **Nonlinear Component Analysis as a Kernel Eigenvalue Problem** | Kernel principal component analysis | Distinguishes nonlinear kernel projection from ordinary SVD/PCA. | Our SVD remains linear; only the classifier uses an RBF kernel. |
| [10](https://doi.org/10.1098/rsta.2015.0202) | Jolliffe et al., 2016, Philosophical Transactions of the Royal Society A: Mathematical, Physical and Engineering Sciences. **Principal component analysis: a review and recent developments** | PCA review | Explains variance-based dimensionality reduction and interpretation. | Retained variance need not preserve label information. |
| [11](https://doi.org/10.1007/BF02288367) | Eckart et al., 1936, Psychometrika. **The Approximation of One Matrix by Another of Lower Rank** | Optimal low-rank matrix approximation | Foundation for truncated-SVD Frobenius approximation. | Reconstruction optimality does not imply classification optimality. |
| [12](https://doi.org/10.1007/BF02163027) | Golub et al., 1970, Numerische Mathematik. **Singular value decomposition and least squares solutions** | Numerical SVD | Numerical computation of singular values and least-squares solutions. | Algorithmic foundation, not an EEG feature-selection result. |
| [13](https://doi.org/10.1109/TAU.1967.1161901) | Welch, 1967, IEEE Transactions on Audio and Electroacoustics. **The use of fast Fourier transform for the estimation of power spectra: A method based on time averaging over short, modified periodograms** | Welch spectral estimation | Averaged modified periodograms motivate the fixed bandpower estimator. | Window/segment choices affect frequency resolution and variance. |
| [14](https://doi.org/10.1016/j.eswa.2018.08.031) | Dose et al., 2018, Expert Systems with Applications. **An end-to-end deep learning approach to MI-EEG signal classification for BCIs** | End-to-end EEG CNN and adaptation | Context for learned EEG representations and personalization. | Different model and validation protocol; not a matched baseline here. |
| [15](https://doi.org/10.1088/1741-2552/aace8c) | Lawhern et al., 2018, Journal of Neural Engineering. **EEGNet: a compact convolutional neural network for EEG-based brain–computer interfaces** | Compact EEG convolutional model | Context for efficient EEG representation learning. | Neural model excluded from implementation scope. |
| [16](https://doi.org/10.1088/1741-2552/aadea0) | Jayaram et al., 2018, Journal of Neural Engineering. **MOABB: trustworthy algorithm benchmarking for BCIs** | MOABB benchmarking | Motivates reproducible multi-dataset BCI evaluation and comparisons. | Our single-dataset exploratory protocol is narrower. |
